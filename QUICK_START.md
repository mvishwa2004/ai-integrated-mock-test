# Quick Start

1. Configure MySQL credentials in `.env.local` as described in `MYSQL_SETUP.md`.
2. Run `mysql_schema.sql` in MySQL Workbench or your provider's SQL editor.
3. Install project dependencies with `npm install`.
4. Start the application with `npm run dev`.
5. Create an account, finish a mock exam, then check the dashboard History page.

The MySQL database schema is maintained in `mysql_schema.sql`. Follow the
current MySQL setup guide rather than older database setup notes.
